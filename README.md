# Homework Hub

> Часть портфолио: [сайт-портфолио](https://auryxn.github.io) — репозиторий сайта [site-admin](https://github.com/auryxn/site-admin).

> Локальное веб-приложение для управления учебными заданиями из Microsoft Teams: сводит все дедлайны в одну доску и автоматически запускает агентов, которые решают задания.

## Что это (простыми словами)

Homework Hub — это лёгкий локальный сервер и веб-страница, которые собирают все твои задания из Microsoft Teams в один понятный список и помогают их выполнять.

- **Сбор заданий.** Скрипт-сканер раз в день (в 21:00) подключается к уже открытому в браузере Teams (через CDP), вытаскивает задания из вкладок «предстоящие / просроченные / выполненные» и сохраняет их в локальный JSON-файл.
- **Доска.** В браузере на `http://127.0.0.1:8787` видно карточки заданий: по дедлайну и по статусу, отдельная вкладка «просрочено». У каждого задания — своя страница с описанием, файлами и ссылкой на исходник в Teams.
- **Выполнение через агента.** Кнопка «Начать выполнять» запускает в фоне настоящего OpenClaw-агента по предмету: он читает задание, готовит решение, коммитит и пушит его в репозиторий `sdc-homework-3`, после чего помечает задание выполненным и присылает уведомление в Telegram. Прогресс агента транслируется прямо в интерфейс (лог в реальном времени).

Для кого: студент, у которого задания размазаны по Teams и который хочет видеть дедлайны в одном месте и частично автоматизировать выполнение.

## Возможности (реальные фичи)

- **Веб-доска заданий:** группировка по дате дедлайна и по статусу, вкладка просроченных, поиск/детали на отдельной странице.
- **Статусы:** `not_started` (не начато), `in_progress` (в работе), `done` (выполнено); «просрочено» вычисляется на лету (дедлайн прошёл, а статус не `done`).
- **Единый источник правды:** `data/assignments.json` — задания, статус, предмет, дедлайн, баллы, файлы, ссылка на репозиторий.
- **Автоматический скан Teams** (`scripts/scan_teams.mjs`) через CDP-браузер OpenClaw (`:18800`), с разпознаванием предмета по названию курса/задания.
- **Запуск агента-исполнителя** (`scripts/spawn_agent.sh`) — реальный OpenClaw-агент с сессией по предмету; прогресс стримится в `data/logs/agent-<id>.log`, статус — в `data/jobs/<id>.json`.
- **Потоковый лог агента** в UI (`/api/assignments/:id/log?stream=1`, SSE) и живой статус (`/api/assignments/:id/status`).
- **Кнопки на карточке:** «Начать выполнять», «Отметить выполненным» (с привязкой ссылки на репозиторий), сброс, удаление, скачивание лога.
- **Профили предметов** (`agents-subjects/*.md`) — контекст, заметки и единый гайд по стилю решений (`STYLE.md`: соразмерность усилий заданию, без кода для теоретических задач).
- **Расписание:** launchd-задача `com.auryxn.homeworkhub` запускает `daily_scan.sh` ежедневно в 21:00; `setup_wake.sh` готовит plist и подсказки `pmset` для пробуждения Mac.

## Стек

- **Backend:** Node.js без внешних зависимостей — только стандартная библиотека (`http`, `fs/promises`, `child_process`), JSON-хранилище с атомарной записью (temp-файл + `rename`).
- **Frontend:** статический HTML/CSS/JS (`web/`), без сборщиков и фреймворков.
- **Сканер Teams:** Node ESM (`scan_teams.mjs`) через CDP/WebSocket, чтение React-fiber пропсов карточек заданий.
- **Вспомогательное:** Python 3 (`import_teams.py` — импорт из выгрузки), bash-скрипты, launchd (macOS), OpenClaw-агенты.
- **Внешнее:** публичный репозиторий `https://github.com/auryxn/sdc-homework-3`.

## Установка и запуск

Требования: Node.js, браузер OpenClaw с залогиненным Teams (для сканера), `gh` авторизован (для агентов).

```bash
cd projects/homework-hub

# Запустить сервер (без зависимостей — ставить нечего)
node server/server.js
# по умолчанию: http://127.0.0.1:8787  (host 127.0.0.1, порт 8787)

# Открыть интерфейс в браузере
open http://127.0.0.1:8787
```

Переменные окружения сервера:

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `PORT` | `8787` | порт HTTP-сервера |
| `HOST` | `127.0.0.1` | адрес прослушивания (локально) |

### Скан заданий из Teams

```bash
# требует запущенного браузера OpenClaw с залогиненным Teams (CDP на :18800)
node scripts/scan_teams.mjs            # обычный скан
node scripts/scan_teams.mjs --dry      # распарсить, но не писать
node scripts/scan_teams.mjs --completed  # заодно вкладка «Выполнено»

# или целиком ежедневная процедура (поднять сервер + скан + сводка)
bash scripts/daily_scan.sh
```

### Ежедневный автозапуск (macOS)

```bash
bash scripts/setup_wake.sh
# скрипт только создаёт plist и печатает команды pmset — сам ничего не загружает
```

### Полезные утилиты

```bash
bash scripts/mark_done.sh <assignment_id> <repo_url>   # отметить выполненным
bash scripts/spawn_agent.sh <id> <subject> <title>     # запустить агента вручную
```

### Основные API-эндпоинты

| Метод | Путь | Что делает |
|---|---|---|
| GET | `/api/health` | проверка живости сервера |
| GET | `/api/assignments` | список заданий (с вычисленным `overdue`) |
| POST | `/api/assignments` | создать/обновить задание (использует сканер) |
| GET | `/api/assignments/:id` | одно задание |
| POST | `/api/assignments/:id/start` | перевести в `in_progress` и запустить агента |
| POST | `/api/assignments/:id/done` | отметить выполненным (+ `repo_url`) |
| POST | `/api/assignments/:id/reset` | сбросить в `not_started` |
| DELETE | `/api/assignments/:id` | удалить задание |
| GET | `/api/assignments/:id/log` | хвост лога агента (`?tail=N`, `?stream=1` — SSE) |
| GET | `/api/assignments/:id/status` | живой статус из файла job |
| GET | `/api/subjects` | агрегаты по предметам |

## Структура проекта

```
homework-hub/
├── server/server.js               # HTTP-сервер: статика + JSON API, запуск агентов
├── web/                           # интерфейс: index.html, assignment.html, agent.html, app.js, style.css
├── data/
│   ├── assignments.json           # главный файл заданий (источник правды)
│   ├── jobs/<id>.json             # состояние job'а агента (pid, статус, длительность)
│   ├── logs/                      # логи сервера, ежедневного скана и агентов
│   └── agent-queue.txt            # очередь запусков агентов
├── agents-subjects/               # по файлу на предмет + STYLE.md (гайд по стилю решений)
├── scripts/
│   ├── scan_teams.mjs             # сканер заданий Teams через CDP
│   ├── daily_scan.sh              # ежедневная процедура (21:00)
│   ├── spawn_agent.sh             # запуск OpenClaw-агента по заданию
│   ├── mark_done.sh               # отметить задание выполненным
│   ├── import_teams.py            # импорт заданий из выгрузки
│   ├── setup_wake.sh              # генерация plist + подсказки pmset
│   └── com.auryxn.homeworkhub.plist  # launchd-задача на 21:00
├── screenshots/                   # скриншоты интерфейса
└── README.md
```
